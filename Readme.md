# What is Project Starfleet?

In simple terms, it's an attempt to write Star Trek: The Next Generation style stories, but with my personal vibe of humanism. Of course this isn't cannonical. Considering I have some ideas for how The Fleet should be re-structured, I assume it never will.

I've chosen to write this mostly through Log entries. I assume it will add some other formats as well, but those are planned yet.

This is currently an Side-Project for me. A welcome Diversion but nothing more.
