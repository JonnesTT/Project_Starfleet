# What is Project Starfleet?

In simple terms, it's an attempt to write a Star Trek: The Next Generation style story, but with my vibe of humanism. Of course this isn't cannonical, and considering I have some ideas for how the Fleet should be structured, I assume it never will.

I've chosen to write this mostly through Log entries. I assume it will add some other formats as well, but those are planned yet.

This is currently an Side-Project for me. A welcome Diversion but nothing more.
